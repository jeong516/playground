# 영웅서기 : 솔티아의 바람 (Web Edition)

추억의 피처폰 액션 RPG **영웅서기(Heroes Lore)**의 감성을 현대 웹 기술(HTML5 Canvas + Web Audio API + Vanilla JS)로 재현한 실시간 액션 RPG 웹앱입니다.

## 주요 특징
- **3개 직업 선택**: 기사 케인 / 도적 레온 / 마검사 루나 (각각 고유 스탯 및 4종 액티브 스킬)
- **실시간 핵앤슬래시 전투**: 방향별 3연타 콤보, 무기 강화 단계별 검기 이펙트, 회피 대시(`Shift`), 넉백/치명타/화면 흔들림
- **5개 연결 월드맵**: 솔티아 마을 → 바람의 초원 → 고요한 숲(미니보스 고블린 족장) → 잊혀진 유적 → 봉인의 제단(최종보스 심연의 기사 바르가스)
- **영웅서기 시그니처 시스템**: 대장장이 장비 강화(`+1`~`+9`), 몬스터 재료 장비 조합(Synthesis), 스탯/스킬 포인트 분배, 4챕터 메인 퀘스트
- **피처폰 키패드 모드**: 상단 `📱 피처폰 키패드` 버튼으로 D-Pad + 1~9 숫자 키패드 토글 지원
- **칩튠 사운드 & 자동 저장**: Web Audio API 합성 BGM/효과음 및 `localStorage` 자동/수동 저장

## 실행 방법
별도 빌드 없이 `index.html`을 브라우저로 열거나 로컬 정적 서버로 실행할 수 있습니다.
```bash
npx serve .
```
